## Hola, soy Rogelio Pavel Hernández Ibáñez 👋
Ingeniero de Control de Calidad Junior con experiencia previa en Soporte Técnico, enfocado en garantizar la calidad del producto antes de su lanzamiento, evitando que la confianza entre la empresa y sus clientes se pierda a futuro. <br>
Tengo experiencia práctica en el analisis de requerimientos para la creación de casos de prueba, la ejecución de diferentes tipos de pruebas manuales, la detección, reporte y seguimiento de bugs. Compruebo el funcionamiento de los elementos que conforman una interface grafica utilizando DevTools y Navegadores Web, valido endpoints de API con Postman, simulo las principales caracteristicas de cualquier dispositivo movil utilizando Android Studio, ejecuto consultas complejas de bases de datos mediante PostgreSQL, y utilizo herramientas de administración y seguimiento de bugs como JIRA y Trello con la precisión técnica necesaria para facilitar la acción inmediata del equipo de desarrollo. <br>
Me especializo en diseñar casos de prueba que combinan el testing manual y validación de datos para asegurar la integridad de los entregables. Mi enfoque esta en garantizar la satisfacción y mejorar la experiencia del usuario, así como la calidad del software.
